# 批量处理使用说明

当前版本包含多轮纠错和正式字段扩展，详细流程见[交互校对说明](REVIEW.md)。

## 聊天框直接操作

直接粘贴多行指令，支持一次处理多名学生：

```text
添加下列学生信息：
2670001 李明
2670002 李华
2670003 张硕
```

批量查找：`查询学号2670001、2670002、2670003的学生信息`。

批量修改：

```text
将以下学生姓名修改为：
2670001 李明同学
2670002 李华同学
```

批量删除：`删除学号2670001、2670002的学生`，核对确认卡片后点击确认。

聊天由DeepSeek提取完整记录并调用批量工具；每轮最多500条写入记录，不再限制为一个学生。对于特别长的名单，推荐使用Excel或批量文本入口，避免模型输出超长。

## 批量文本入口

点击聊天输入框旁或“学生管理”页面的“批量处理”。选择新增、查找、修改、删除、新增或更新，再粘贴名单。可直接从Excel复制两列，首行可带“学号 姓名”表头。

新增和修改可填写学号、姓名及自定义字段，含空格的值建议加引号或使用Tab/逗号分隔。查找、删除可每行一个学号；删除若附姓名，会核对目标。先确认字段对应、修正或明确排除问题行，再核对最终预览并确认。

这个入口可直接使用规则与手动校对，无需调用模型；也可点击“请DeepSeek推测”获得建议。处理结果同步记录在当前会话中。

## Excel导入

点击“Excel导入”，可下载包含当前正式字段的模板，填写数据后上传。初始模板只有以下两列：

| 学号 | 姓名 |
|---|---|
| 2670001 | 李明 |
| 2670002 | 李华 |

支持`.xlsx`、`.xls`，最大2MB，每批最多500条记录；完全空白的数据行忽略。默认读取首个非空可见工作表的首个非空行作为表头，可在校对界面调整工作表和表头行。全部非空列保留，别名由用户确认；额外列必须明确映射、新增正式字段或选择忽略。

三种模式：

- **仅新增**：学号不存在才新增，已存在标为失败。
- **仅更新**：按现有学号更新姓名，不存在的学号标为失败。
- **新增或更新**：不存在则新增，存在则更新姓名，相同信息跳过。

更新以现有学号定位，可更新姓名或正式字段；需要更换学号时，选择更新模式，将对应列映射为“新学号”。新增学生必须填写全部必填字段，更新未提供的现有字段保持原值。

学号必须是7位数字且首位不能为0，姓名最多15个字符，性别只能为男/女。Excel读取时保留原值供校对，长度或前导零不合规时提示修正；不会自动截短或补零。公式和超出Excel精度范围的数字仍会标为问题单元格。

## 预览和结果

预览不写入学生记录，显示每行的原值、新值、操作和错误。问题行全部修正或被明确排除后才能确认。新增字段另有一次明确确认，会保存字段及所有已有学生的补全值；之后再确认本批学生操作。最终批量写入各行独立事务提交。

- 同一批次重复的学号全部提示，请自行修正、排除，或明确选择仅保留第一条。
- 校对阶段不会自动跳过错误；执行期间若发生并发冲突，保留逐行成功/失败结果，提供仅修正失败记录入口。
- 校对草稿保留1小时，常规AI修改/删除待办仍为5分钟；确认时重新检查数据及字段结构，避免覆盖新内容。
- 重复点击确认返回已缓存结果，不重复执行。
- 关闭弹窗后，待确认卡片仍在当前AI会话中；也可取消或重新选择。
- 正式字段会成为`student`物理列；每次结构变更保留升级前备份表。没有新增导入日志表。

Excel由Java使用Apache POI在本地解析，工作簿文件不上传给DeepSeek。主动请求模型建议时会发送列名和少量样例；聊天纠错时会发送必要的草稿问题和前20行摘要。
